# Customer Analytics &  Business Intelligence

## Project Overview
This project implements an end-to-end customer analytics workflow using Python, SQL, and Power BI. It covers data preparation, exploratory analysis, database querying, dashboard development, and business insight generation.

## Objectives
- Clean and transform retail customer data for analysis.
- Analyze customer segments, purchase patterns, loyalty, and purchase drivers using SQL.
- Build an interactive Power BI dashboard to communicate key trends and insights.
- Summarize findings and actionable business recommendations in a report and presentation.

## Project Files
- `customer_shopping_behavior.csv` — source dataset.
- `Customer_Shopping_Behavior_Analysis.ipynb` — data import, exploration, cleaning, and database-loading workflow.
- `customer_behavior_sql_queries.sql` — SQL analysis and business queries.
- `customer_behavior_dashboard.pbix` — interactive Power BI dashboard.
- `Customer Shopping Behavior Analysis.pdf` — project report.
- `Customer-Shopping-Behavior-Analysis.pptx` — presentation deck.
- `Business Problem  Document.pdf` — business problem and project requirements.

## Workflow
1. Load and inspect the customer shopping dataset.
2. Clean and transform the data for analysis.
3. Load the prepared data into a SQL database.
4. Run SQL queries to answer business questions and identify customer trends.
5. Connect the analyzed data to Power BI and build an interactive dashboard.
6. Document the findings, insights, and recommendations in the report and presentation.
